# 📈 주식/산업 리포트 트렌드 인텔리전스 (Report Trend Intelligence)

증권사 및 산업 리포트 원문(PDF)을 수집하여 최대 30페이지 전체 본문을 파싱하고, **한국어 형태소 분석(`Kiwi`)**과 **로컬 LLM(`Ollama` + `Qwen 2.5 7B`)**을 결합하여 시장의 급상승 테마 발굴부터 심층 3단 요약(투자포인트/실적전망/리스크)까지 제공하는 올인원 투자 인텔리전스 플랫폼입니다.

---

## 🏗️ 시스템 아키텍처 및 동작 흐름

```
[1. 크롤러] ──> 네이버 금융 리포트(기업/산업/시황) 메타데이터 & PDF 링크 수집
      │
[2. PDF 파서] ──> PyMuPDF 기반 최대 30페이지 원문 텍스트 추출 및 정제
      │
[3. NLP 엔진] ──> Kiwi 형태소 분석기로 금융 전문용어 추출, 불용어 제거 및 빈도 집계
      │
[4. 트렌드 분석] ──> 시계열 급상승(Surge) 점수 계산, 섹터별 관심도 분석, 타임라인 생성
      │
[5. 로컬 LLM] ──> Ollama (Qwen 2.5 7B) 심층 3단 분석 (한 줄 결론/투자포인트/전망/리스크)
      │
[6. 웹 대시보드] ──> FastAPI + Glassmorphism UI를 통한 실시간 시각화 & 모달 브리프
```

## 🚀 현재 구현된 기능 (Current Features)

### 1. 데이터 수집 & 텍스트 파싱
- **다분야 리포트 자동 수집**: 기업, 산업, 시황 분석 리포트 메타데이터 및 원문 링크 수집
- **원문 PDF 다운로드 및 캐싱**: 로컬 디렉토리(`data/pdfs/`)에 원본 파일 보관
- **고속 PDF 파싱**: `PyMuPDF`를 활용하여 **최대 30페이지 전체 본문 텍스트** 추출
- **텍스트 노이즈 정제**: 이메일, URL, 단순 페이지 번호 등 불필요한 텍스트 1차 필터링

### 2. 한국어 형태소 분석 & 트렌드 엔진
- **Kiwi 한국어 형태소 분석**: 명사(NNG, NNP) 및 영문 약어(SL, 예: HBM, CXL, AI 등) 정밀 추출
- **금융 전문 사전 & 불용어 필터**: '투자', '매수', '전망' 등 의미 없는 빈출어를 제거하고 핵심 테마어 집중
- **급상승(Surge) 테마 발굴**: 이전 기간 대비 최근 언급 빈도가 급증한 테마 TOP 랭킹 산출
- **시계열 언급 추이 분석**: 주요 키워드의 일자별 출현 추세 타임라인 생성

### 3. 로컬 LLM (`Ollama` + `Qwen 2.5:7b`) 심층 인텔리전스
- **데일리 AI 마켓 인텔리전스 브리프**: 최근 리포트들을 종합하여 시장 전체의 핵심 모멘텀과 섹터 트렌드 요약
- **테마별 종합 브리프**: 특정 테마 클릭 시 관련 복수 리포트를 종합 분석(주목 배경, 컨센서스, 수혜주, 리스크)
- **개별 리포트 3단 심층 분석**:
  - 🎯 **한 줄 핵심 결론**
  - 📊 **시장 감성 평가** (긍정 Bullish / 중립 Neutral / 신중 Bearish)
  - 📌 **핵심 투자 포인트 3선**
  - 📈 **실적 및 밸류에이션 전망**
  - ⚠️ **주요 리스크 요인**
- **대시보드 목록 즉시 노출**: 리포트 테이블에 AI 한 줄 요약 및 감성 태그가 바로 표시됨
- **SQLite 캐싱**: 생성된 AI 요약은 DB에 영구 저장되어 다음 조회 시 **0초 즉시 로딩**

### 4. 인터랙티브 웹 대시보드
- **Glassmorphism 다크 테마 UI**: 반응형 레이아웃 및 모던 디자인
- **Chart.js & WordCloud2**: 시계열 추이 차트, 키워드 워드클라우드, 섹터별 점유율 차트
- **인터랙티브 모달**: 리포트/테마 클릭 시 즉시 AI 심층 브리핑 팝업
- **원클릭 백그라운드 수집 버튼**: 대시보드 상단에서 실시간 리포트 수집/분석 트리거

## 📂 프로젝트 구조

```
report_trand/
├── crawler/
│   └── report_crawler.py      # 리포트 메타데이터 및 PDF 링크 크롤러
├── processor/
│   ├── pdf_parser.py          # PDF 다운로드 및 30페이지 텍스트 추출
│   ├── nlp_engine.py          # Kiwi 형태소 분석 및 금융 불용어 처리
│   └── llm_summarizer.py      # Ollama (Qwen 2.5) 심층 3단 요약 및 테마 브리프
├── analyzer/
│   └── trend_analyzer.py      # TF-IDF, 급상승 지수, 시계열 타임라인 분석 엔진
├── db/
│   └── database.py            # SQLite DB 관리 (리포트, 키워드, AI요약, 캐시)
├── app/
│   ├── main.py                # FastAPI 백엔드 REST API
│   └── static/
│       ├── index.html         # 웹 대시보드 마크업
│       ├── css/style.css      # 다크 테마 Glassmorphism 스타일
│       └── js/dashboard.js    # 차트, 워드클라우드, 모달 및 LLM 통신 로직
├── data/                      # SQLite DB(reports.db) 및 PDF 원본 저장소
├── pipeline.py                # 전체 수집 -> 파싱 -> Kiwi 분석 -> LLM 요약 파이프라인
├── main.py                    # 실행 엔트리포인트 (CLI / 웹서버 구동)
└── requirements.txt           # 의존성 패키지 목록
```

## 🛠️ 설치 및 실행 방법

### 1. 패키지 설치 및 Ollama 구동
```bash
pip install -r requirements.txt
ollama run qwen2.5:7b
```

### 2. 대시보드 서버 및 파이프라인 실행
```bash
# 웹 대시보드 실행 (자동 브라우저 열림)
python main.py --port 8000

# 또는 수집/분석 파이프라인만 실행
python main.py --crawl-only --pages 3 --max-pdfs 40
```

## 🔮 앞으로 성능 향상 및 고도화를 위해 해야 할 것들 (Roadmap)

### 1. 정량 데이터 수치 파서 구축 (우선순위: ⭐⭐⭐⭐⭐)
- **목표주가(TP) / 투자의견(Buy/Hold/Sell) 정규식 추출**:
  - 리포트 첫 페이지의 목표주가 상향/하향 여부, 목표주가 괴리율 자동 계산
  - 대시보드에 **"오늘 목표주가 상향 종목 TOP 5"** 전용 탭 추가
- **재무제표 요약 테이블 파싱**: 매출액, 영업이익 증감률(YoY, QoQ) 수치 추출

### 2. LLM 추론 속도 및 파이프라인 가속화 (우선순위: ⭐⭐⭐⭐)
- **비동기 배치 큐 (Async Worker)**: 크롤링 완료 후 백그라운드 큐를 통해 GPU VRAM에 무리를 주지 않으면서 순차적 일괄 요약
- **스트리밍(Streaming) 응답 적용**: 대시보드 모달 오픈 시 실시간으로 글자가 타이핑되듯 나타나는 SSE(Server-Sent Events) 적용

### 3. 섹션 가중치 및 노이즈 정제 고도화 (우선순위: ⭐⭐⭐⭐)
- **섹션별 가중치 차등 부여**: 리포트의 `제목(3x)`, `소제목(2x)`, `초록/결론(2x)`, `일반 본문(1x)`, `면책조항(0x)`으로 가중치를 부여하여 키워드 트렌드 그래프의 노이즈 제거
- **증권사별 템플릿 맞춤 전처리**: 증권사마다 다른 리포트 헤더/푸터/도표 캡션 자동 인식 제거

### 4. RAG 기반 "리포트 전체 질의응답" 구축 (우선순위: ⭐⭐⭐)
- **로컬 벡터 DB (ChromaDB / FAISS) 연동**:
  - 수집된 수백 개의 리포트를 벡터화하여 저장
  - 대시보드 검색창에서 *"올해 4분기 HBM 수혜주와 리스크 정리해줘"* 와 같이 자연어 질의 시 관련 리포트들을 모아 즉시 답변 생성

### 5. 실시간 알림 연동 (우선순위: ⭐⭐⭐)
- **텔레그램 / 디스코드 웹훅 연동**:
  - 장 시작 전 아침 8시에 "오늘의 AI 마켓 브리프" 및 "전일 대비 급상승 테마 TOP 5" 자동 알림 발송
